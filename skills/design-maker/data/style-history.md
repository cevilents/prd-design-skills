# Riwayat Gaya design-maker

Satu baris per proyek, terbaru di bawah. Dipakai langkah 2a untuk menghindari keluarga gaya dan pasangan font yang sama berulang. Kode keluarga mengikuti `references/style-families.md`.

Format: `YYYY-MM-DD · <nama produk> · <jenis produk> · terpilih: <kode keluarga> (<font display> + <font teks>) · ditolak: <kode>, <kode>`
