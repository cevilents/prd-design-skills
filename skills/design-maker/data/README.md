# data/

`style-history.md` adalah riwayat gaya pribadi milik setiap pengguna dan **tidak ikut di-commit** (ada di `.gitignore`). File ini dibuat otomatis oleh `design-maker` pada pemakaian pertama.

Format satu baris per proyek, terbaru di bawah:

```
YYYY-MM-DD · <nama produk> · <jenis produk> · terpilih: <kode keluarga> (<font display> + <font teks>) · ditolak: <kode>, <kode>
```

Kode keluarga gaya mengikuti `references/style-families.md`.
